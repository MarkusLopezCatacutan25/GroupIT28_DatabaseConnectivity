## Play

Reopen MainMenu after Unity imports the changed scripts and scene. Choose the Batangas recipe, resolve trivia, and proceed to the kitchen. Choose **Guided practice / start here** for the first attempt. Tap garlic, luyang dilaw, and chicken, then tap or drag the knife onto the small board. The game opens a close-up board at a downward oblique angle. Touch the START marker, drag down the green guide, and lift at FINISH. The knife follows the pointer, accepted strokes add pieces, and progress advances through three garlic and three turmeric strokes. Tap Start cooking, then follow the ingredient and heat instructions. Switch the flame off before plating.

## Timing and requirements

The user explicitly requested less pressure and proposed a stopwatch. Guided practice therefore has no preparation or cooking expiry. Its stopwatch measures active unscaled game time from mode selection to the terminal result, including the full incoming frame duration. Pauses and background/focus loss stop both clock and simulation and cancel any unfinished gesture; Resume is explicit. Mode choice and result review do not count toward active time. The clock displays tenths; the result and local practice history retain separate prep/cooking values in seconds. This is game-session duration, not a real recipe cooking duration or a wall-clock measurement including breaks.

The optional timed challenge uses 120 seconds of prep plus the existing one-time 15-second correct-trivia bonus; its cooking countdown remains 75 seconds. This is a deliberate new UI default for challenge preparation, superseding the earlier short-guide implementation for new scene attempts. The model's existing one-argument constructor retains 60/75 prep for backwards-compatible callers and rule checks. The inherited recipe, distractor, tool matching, normalized vector alignment and stability, chronological additions, searing, retained heat, initial uncovered/unstirred simmer, flame-off plating, penalties, raw-skill grading, trivia multiplier, retry handoff, and offline persistence remain in use. The 4-second sear and 12-second simmer are explicitly simulated intervals. Practice retains these procedure/heat checks and can still fail for sustained overheating or poor performance.

Practice uses the same skill breakdown for feedback but never enters the ranked timed-score outbox. Save practice records an idempotent local result in Application.persistentDataPath/savorpinoy-practice-history.json, with run ID, optional chef alias, active/prep/cooking seconds, accuracy, raw score, mistakes, and stars. Ranked attempts retain the existing six-field cloud schema and pending-score service. No database configuration or network submission was changed.
