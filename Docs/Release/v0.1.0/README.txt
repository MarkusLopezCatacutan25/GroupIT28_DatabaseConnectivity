WHAT IT IS
A 2D culinary simulator that teaches two CALABARZON heritage dishes:
Batangas Adobo sa Dilaw and Quezon Pancit Habhab.

REQUIREMENTS
- Windows 10 or 11, 64-bit
- Internet connection (needed for guest sign-in and saving)

HOW TO RUN
1. Right-click SavorPinoy-v0.1.0-win64.zip and choose "Extract All".
   Do not run the game from inside the ZIP.
2. Open the extracted SavorPinoy-v0.1.0 folder.
3. Double-click SavorPinoyPrototype.exe.
   If Windows SmartScreen appears, click "More info", then "Run anyway".
4. Click Play and sign in as a guest.
5. Answer the province trivia, then choose Guided practice or Timed challenge.
6. Prepare and cook the dish, plate it with the flame off, then click Save on
   the results screen. Wait until the save is confirmed before continuing.
7. To quit, return to the main menu and click Exit.

VERSION
The version is shown at the bottom-right of the main menu and in BUILD_INFO.txt,
which also records the exact source commit.
