INCLUDED IN THIS VERSION
- Main menu (Play, Options for sound, Exit) with version label
- Guest sign-in using Firebase Anonymous Authentication
- Philippines map, CALABARZON pin and a random first province
- Regional trivia: correct answer unlocks the recipe, adds 15 s and a 1.25x multiplier;
  a wrong answer or timeout shows an explanation and allows a retry
- Two recipes: Batangas Adobo sa Dilaw and Quezon Pancit Habhab
- Guided practice (no time limit) and Timed challenge (240 s preparation, 75 s cooking)
- Drag-and-drop preparation and cooking, vessel states, steam and bubble cues,
  plating with the flame off
- Scoring 0 to 9,375 with 1 to 3 stars
- Verified save: acknowledged Firebase write plus matching read-back before Continue unlocks
- Attempt history (last 20) and Top 10 board
- Heritage response and routing to the other province

FIXED
- Quezon saves were rejected because the deployed database rules accepted only the
  Batangas dish. Two-dish rules were deployed and verified live on 8 November 2026.
- Removed Unity crash-recovery scenes and unused CookingAttempt constants (PR #3).

KNOWN ISSUES
- Score and timestamp are generated by the game client.
- The guest account belongs to one installation; reinstalling or using another PC
  starts a new player.
- Unsent saves wait in a local outbox that is not encrypted and is not retried automatically.
- The Top 10 board ranks attempts, so one player can appear more than once.
- An internet connection is required to save.

NOT YET INCLUDED
- Android build and touch controls (planned for 0.2.0)
- Cooking habits, food encyclopedia and tool upgrades
- More provinces and a campaign system
- Classroom usability evaluation and CIHM adviser content review
